# Compact README header prompts

Generated with the built-in imagegen tool from the original Joinery cover.

The header is displayed at a maximum width of 640 pixels. Separate image backgrounds target GitHub's standard light and dark themes. These files do not have alpha transparency.

## Initial layout

The first edit established the compact composition. Its requested transparency was not produced; it returned an RGB image with a checkerboard. That intermediate image is not included in the project. The following edits replaced its background.

```text
Use case: precise-object-edit.
Edit target: the supplied uji Joinery cover.
Goal: adapt this exact visual identity into a COMPACT, TRANSPARENT header that blends directly into a GitHub README instead of looking like a large rectangular poster.
Output: wide 3:1 canvas, approximately 1920 x 640. Genuine transparent alpha background everywhere behind the letters and wooden object. Absolutely no ivory paper rectangle, no paper grain in empty space, no painted checkerboard, no white matte, no backdrop, no floor, no drop shadow.
Preserve: the name, exact spelling, exact wording, bold rounded lowercase typography style, the same wooden U joint sculpture and its recognizable assembly geometry, engraved wood grain, dark evergreen color #26372E, exposed raw wood end grain, small suspended vermilion peg and restrained fine guide marks near the sculpture. Do not invent a new wooden object. This is a layout and background adaptation of the existing artwork.
Layout: create a short horizontal lockup. Text group on left approximately 60% and the same wooden U illustration on the right approximately 33%. Keep generous clear gap between groups. Scale the entire sculpture to fit within the height with no cropping; leave about 7% transparent padding top and bottom. Keep the illustration visibly smaller relative to the canvas than in the original cover. The name "uji" is large on the left above the description but not overwhelming; description must be clean and readable at a displayed header width of 640 pixels. Text baseline and overall group are vertically centered relative to the sculpture.
Exact text, without additions: "uji", then "A coding agent you can" on one line and "shape with Lua." on the next. Keep dark evergreen text for a LIGHT page background.
Constraints: no new text, no frame, no border, no gradient, no glow, no other ornaments. Entire background genuinely transparent. Preserve identity and wording while changing only layout and removing the background.
```
