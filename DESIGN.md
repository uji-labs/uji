# Visual identity

Joinery is the visual foundation for uji. The wooden **u** has exposed joints and a vermilion key, reflecting how you can fit its tools, commands and windows to your workflow. The key also echoes a terminal block cursor.

Warm paper, deep green ink and engraved wood grain carry the artwork. Keep text and code crisp, with vermilion reserved for small accents.

| Color | Hex |
|---|---|
| Paper | `#F3EFDF` |
| Ink | `#26372E` |
| Olive | `#8B9475` |
| Wood | `#C8BA96` |
| Vermilion | `#C65036` |
